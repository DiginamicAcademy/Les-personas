# Le dossier `modeles`

Les modèles bureautiques du cours, au format OpenDocument. Ils s'ouvrent avec
LibreOffice, Microsoft Office, Google Docs / Sheets ou OnlyOffice.

| Fichier | Contenu |
|---|---|
| `persona-tableur-modele.ods` | classeur de travail vierge : entretiens, variables comportementales, fiche persona, priorisation |
| `persona-tableur-exemple.ods` | le même classeur, rempli avec les données de l'exemple Panier Local |
| `persona-fiche-modele.odt` | fiche persona à diffuser, avec les consignes de rédaction en italique gris |
| `persona-fiche-exemple.odt` | la fiche de Nadia Benali, canvas en annexe |
| `persona-canvas-modele.ods` | canvas persona sur une page A4 paysage, à remplir dans le tableur ; jauges calculées à partir d'un pourcentage |
| `persona-canvas-exemple.ods` | le même canvas, rempli pour Nadia Benali |
| `persona-canvas-modele.odt` | canvas persona sur une page A4 paysage, à remplir dans le traitement de texte |
| `persona-canvas-exemple.odt` | le même canvas, rempli pour Nadia Benali, illustration comprise |

Leur usage est détaillé au chapitre 06 du cours. Le canvas graphique, lui, est
dans `assets/` (`persona-canvas-vierge.svg` et `persona-canvas-exemple.svg`).

Ce dossier n'est pas repris dans le support PDF : seuls les `.md` de la racine
le sont.
