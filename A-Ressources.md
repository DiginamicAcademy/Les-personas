# Ressources

## Glossaire

| Terme | Définition |
|---|---|
| **Anti-persona** | persona pour laquelle on décide explicitement de ne pas concevoir |
| **Canvas persona** | représentation graphique d'une persona sur une page, à zones fixes |
| **Entretien semi-directif** | entretien guidé par des thèmes plutôt que par des questions fermées |
| **Parcours d'achat** | étapes par lesquelles passe un acheteur : découverte, comparaison, décision, fidélisation |
| **Parcours utilisateur** | suite des étapes vécues par une persona pour atteindre un objectif |
| **Persona** | personnage fictif, fondé sur des données, représentant un groupe d'utilisateurs aux objectifs et comportements proches |
| **Persona commerciale** (*buyer persona*) | persona qui décrit la décision d'achat : déclencheurs, freins, critères, parcours d'achat |
| **Persona d'exploitation** | persona décrivant ceux qui font fonctionner le système : astreinte, support |
| **Persona d'usage** | persona qui décrit l'usage d'un produit ou d'un service, pour le concevoir |
| **Persona interne** | persona décrivant des collaborateurs utilisateurs d'un outil métier |
| **Persona primaire** | persona pour qui l'interface est conçue en priorité |
| **Persona secondaire** | persona dont les besoins s'ajoutent à ceux de la primaire sans les contredire |
| **Proto-persona** | persona provisoire, rédigée sans recherche, à vérifier sur le terrain |
| **Récit utilisateur** | description d'un besoin sous la forme "en tant que…, je veux…, afin de…" |
| **Saturation** | moment où de nouveaux entretiens n'apportent plus d'information nouvelle |
| **Scénario** | récit d'un moment d'usage, au présent, du point de vue de la persona |
| **Variable comportementale** | axe sur lequel les utilisateurs diffèrent et qui change leur usage du produit |
| **Verbatim** | phrase prononcée par un participant, rapportée mot pour mot |

## Bibliographie

- Alan Cooper, *The Inmates Are Running the Asylum*, Sams, 1999 : l'ouvrage
  qui popularise les personas.
- Alan Cooper, Robert Reimann, David Cronin, Christopher Noessel,
  *About Face: The Essentials of Interaction Design*, Wiley, 4ᵉ édition,
  2014 : la méthode des variables comportementales, en détail.
- John Pruitt, Tamara Adlin, *The Persona Lifecycle: Keeping People in Mind
  Throughout Product Design*, Morgan Kaufmann, 2006 : créer, diffuser, faire
  vivre et retirer une persona.
- Lene Nielsen, *Personas - User Focused Design*, Springer, 2ᵉ édition,
  2019 : une approche centrée sur le récit et l'engagement de l'équipe.
- Jeff Gothelf, Josh Seiden, *Lean UX*, O'Reilly : les proto-personas dans une
  démarche itérative.
- Adele Revella, *Buyer Personas*, Wiley, 2015 : la persona commerciale et ses
  cinq rubriques de décision d'achat.
- Steve Portigal, *Interviewing Users*, Rosenfeld Media : mener des
  entretiens utilisateurs.

## En ligne

- [Nielsen Norman Group : articles sur les personas](https://www.nngroup.com/topic/personas/)
  (en anglais).
- [CNIL : le RGPD et les données personnelles](https://www.cnil.fr/fr/rgpd-de-quoi-parle-t-on)
  pour cadrer la collecte.
- [LibreOffice](https://fr.libreoffice.org/) pour ouvrir et modifier les
  modèles OpenDocument.
- [Inkscape](https://inkscape.org/fr/) pour modifier le canvas SVG.

## Pour aller plus loin

- **Jobs to be done** : une approche complémentaire, centrée sur la "tâche"
  que l'utilisateur confie au produit plutôt que sur son profil.
- **Cartographie d'empathie** (*empathy map*) : un format d'atelier rapide pour
  préparer la rédaction d'une persona.
- **Cartographie de parcours** (*customer journey map*) : le prolongement
  naturel de la section 2 du chapitre 07.
